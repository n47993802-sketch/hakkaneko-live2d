# 公開排單表模板

這份模板是給公開試算表使用，網站只應該讀取這份公開資料，不要直接讀私人表。

## 建議欄位順序
1. 月份
2. 委託者稱呼
3. 委託編號
4. 委託品項
5. 排單進度
6. 截止日期
7. 完成日期
8. 備註(A)

## 建議公開規則
- 委託者稱呼只顯示第一個字，其餘字元用 `*` 取代。
- 委託品項與排單進度建議保留穩定代碼，並由網站依語系轉成顯示文字。
- 完成日期建議使用 `yyyy/mm/dd`。
- 備註欄只放可公開內容。

## Google Sheets 範例公式
假設私人表工作表名稱為 `私人表`，公開表工作表名稱為 `公開表`。
以下公式以你截圖中的私人表欄位為準：`A` 月份、`B` 委託者稱呼、`C` 委託編號、`D` 委託品項、`E` 排單進度、`H` 完成日期、`I` 截止日期、`M` 附註A。

### A 欄：月份
在 `公開表!A2` 輸入：

```excel
=ARRAYFORMULA(IF(LEN(私人表!A2:A)=0,"",私人表!A2:A))
```

### B 欄：委託者稱呼
在 `公開表!B2` 輸入：

```excel
=ARRAYFORMULA(IF(LEN(私人表!B2:B)=0,"",LEFT(私人表!B2:B,1)&REPT("*",LEN(私人表!B2:B)-1)))
```

### C 欄：委託編號
在 `公開表!C2` 輸入：

```excel
=ARRAYFORMULA(IF(LEN(私人表!C2:C)=0,"",私人表!C2:C))
```

### D 欄：委託品項
在 `公開表!D2` 輸入：

```excel
=ARRAYFORMULA(IF(LEN(私人表!D2:D)=0,"",私人表!D2:D))
```

### E 欄：排單進度
在 `公開表!E2` 輸入：

```excel
=ARRAYFORMULA(IF(LEN(私人表!E2:E)=0,"",私人表!E2:E))
```

### F 欄：截止日期
在 `公開表!F2` 輸入：

```excel
=ARRAYFORMULA(IF(LEN(私人表!I2:I)=0,"",TEXT(私人表!I2:I,"yyyy/mm/dd")))
```

### G 欄：完成日期
在 `公開表!G2` 輸入：

```excel
=ARRAYFORMULA(IF(LEN(私人表!H2:H)=0,"",TEXT(私人表!H2:H,"yyyy/mm/dd")))
```

### H 欄：備註(A)
在 `公開表!H2` 輸入：

```excel
=ARRAYFORMULA(IF(LEN(私人表!M2:M)=0,"",私人表!M2:M))
```

## 網站端接法
等公開表建立完成後，把公開試算表設定成可公開讀取，再將發佈後的 CSV 或 JSON 連結填入網站設定檔即可。
