model-config.js 控制說明

檔案位置
- creative/model/model-config.js

用途
- 集中管理模型展示資料，不必再改 model-render.js 內部邏輯。
- 目前頁面會讀取：模型清單、動畫按鈕、表情區設定。

注意
- 你先前提到的 TrackingA / TrackingB 只是參考，這份預設設定沒有強制寫入這兩筆。
- 如果路徑含空白或中文，請用 encodeURI(...) 包起來。

基本結構
window.MODEL_RENDER_CONFIG = {
  defaultModelKey: "hakkanekoqq",
  modelOrder: ["hakkanekoqq", "test"],
  models: {
    yourModelKey: {
      key: "yourModelKey",
      label: "下拉選單顯示名稱",
      displayName: "模型資訊名稱",
      sourceLabel: "models/XXX/YYY.model3.json",
      modelUrl: encodeURI("https://.../YYY.model3.json"),
      motions: [
        {
          key: "motionKey",
          name: "MotionGroupName",
          label: "按鈕文字",
          icon: "material_symbol_name",
          buttonClass: "按鈕樣式 class 字串"
        }
      ],
      expressionMode: "presets" 或 "sliders",
      expressions: [
        {
          key: "angry",
          label: "生氣",
          file: encodeURI("https://.../1.exp3.json")
        }
      ],
      sliderLabels: {
        expressionHappy: "開心",
        expressionSurprised: "驚訝"
      },
      sliderStyles: {
        expressionHappy: "accent-blue-500",
        expressionSurprised: "accent-indigo-500"
      }
    }
  },
  expressionParams: {
    happy: ["ParamA", "ParamB"],
    surprised: ["ParamC"]
  },
  runtimeParams: {
    autoBlink: ["ParamEyeLOpen", "ParamEyeROpen"],
    autoBreath: ["ParamBreath"]
  }
};

欄位說明
- defaultModelKey: 預設載入的模型 key。
- modelOrder: 下拉選單顯示順序。
- models: 每個模型的完整設定。
- motions.name: 目前是呼叫 live2dModel.motion(name) 的 group 名稱，不是檔名。
- expressions.file: exp3.json 路徑，按下按鈕時套用。
- expressionMode:
  - presets: 顯示按鈕型表情。
  - sliders: 顯示拉桿型表情。
- expressionParams: sliders 模式會用到的參數映射。
- runtimeParams: 目前先保留作為資料註記，後續可接到即時參數控制。

常見錯誤排查
1) 按鈕有出現但點了沒反應
- 檢查 motions.name 是否對應 model3.json 內真正的 Motion Group 名稱。

2) 表情按鈕點了沒變化
- 檢查 exp3.json URL 是否可直接開啟。
- 檢查是否有跨網域或 404。

3) 模型載入失敗
- 先確認 modelUrl 可在瀏覽器直接下載。
- URL 有空白或中文時務必使用 encodeURI。
